01 A little context

How this started

I like software that gets out of the way.

My foundation started in high school through Informatics Practices at O.P. Jindal School. Learning the basics of Python quickly turned into an interest in making tools that solve a real, ordinary problem.

Before IILM University, I took an intentional gap year. It gave me space to work out what I actually wanted to build and to develop the habit of learning without waiting to be told what comes next.

“If it is annoying to do by hand, I will probably try to automate it.”

03 Case file

001 / shipped

A desktop file organiser for Windows

Sorta

One small answer to a familiar question: why am I still moving these files by hand?

The problem

Downloads and working folders become messy fast. Sorting them is repetitive, easy to postpone, and somehow always waiting for later.

The build

A Python and tkinter desktop utility that groups files into the right folders, with undo and redo when you want a decision back.

The result

My first open-source release: a real Windows app someone can download and use.
